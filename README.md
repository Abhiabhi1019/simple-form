# Simple Web Form

A simple web application built using HTML, CSS, JavaScript, PHP and MySQL.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git
- GitHub

## Features

- User registration form
- Client-side validation
- Server-side validation
- MySQL data storage
- PHP backend
- Git version control

## Project Structure

simple-form/
├── api/
├── config/
├── css/
├── js/
├── sql/
├── index.php
└── README.md

## Run Locally

Start PHP server:

php -S localhost:8000

Open:

http://localhost:8000
